# DeepShrink — Desktop Releases

Signed, notarized macOS builds of the **DeepShrink** desktop app.

## Install

- **Homebrew:** `brew install --cask deeplabua/tap/deepshrink`
- **Direct:** download the latest `.dmg` from [Releases](https://github.com/deeplabua/deepshrink-desktop-releases/releases/latest), open it, and drag **DeepShrink** to Applications.

The app auto-updates itself via a signed update feed (`latest.json`).

macOS 13 (Ventura) or later · Apple Silicon + Intel (universal).
